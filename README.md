# Python Exercises

Small Python practice programs.

## Tech Stack

- Python 3 (standard library only)

## Programs

### Password Generator (`password_Generator.py`)

A command-line app that generates a random password of the length the user asks for.

- Asks how many characters the password should have and keeps asking until a whole number of 8 or more is entered.
- Builds the password from letters, uppercase letters, digits and punctuation, shuffles it and prints it.

## How to Run

```bash
python password_Generator.py
```

Example:

```
How many characters for the password? : 12
your password is: 3k]G9a@Lq7#V
```
